# LinguaFree — PHP + MySQL Language Learning Platform

A bilingual-ready (English/Hindi account preference) free-course learning platform starter with public course catalogue, student enrolment and progress, teacher course/lesson/quiz authoring, and admin user management.

## Included features
- Responsive public website and course catalogue (12 seeded language courses)
- Searchable courses, course details and free enrolment
- Student registration/login with PHP password hashing and session regeneration
- Student dashboard, lesson reading, audio/video links, MCQ quiz checking and progress records
- Teacher dashboard, create/edit courses, lessons, publish controls and quiz authoring
- Admin dashboard, user/teacher/admin role management and account suspension
- MySQL schema with foreign keys and indexes
- CSRF tokens on POST forms, prepared statements, HTML escaping and role checks
- English/Hindi preferred-language field

## Requirements
- PHP 8.1+ (8.2+ recommended)
- MySQL 8.0+ or MariaDB 10.5+
- Apache with PHP support (or another PHP web server)
- PHP PDO MySQL extension and mbstring

## Local installation (XAMPP)
1. Copy the `LinguaFree` folder into `C:/xampp/htdocs/`.
2. Start Apache and MySQL in XAMPP.
3. Open phpMyAdmin at `http://localhost/phpmyadmin`.
4. Import `database/schema.sql`. It creates the `linguafree` database and sample course catalogue.
5. Open `config/config.php` and set DB_HOST, DB_NAME, DB_USER, DB_PASS and BASE_URL. For the default XAMPP install, `BASE_URL` is `/LinguaFree` if the folder is named `LinguaFree`.
6. Visit `http://localhost/LinguaFree/`.

## Create the first administrator
For safety, public registration can only create student accounts. Create the first admin directly in the database using a password hash generated by PHP:

```php
<?php echo password_hash('Use-A-Strong-Unique-Password', PASSWORD_DEFAULT), PHP_EOL;
```

Run that snippet locally (for example `php -r "echo password_hash('Use-A-Strong-Unique-Password', PASSWORD_DEFAULT), PHP_EOL;"`), then insert the hash in phpMyAdmin:

```sql
INSERT INTO users (name,email,password_hash,role,preferred_language)
VALUES ('Site Admin','admin@example.com','PASTE_GENERATED_HASH_HERE','admin','en');
```

Create teacher accounts from Admin Dashboard → Create user / teacher. Do not make a public registration form that accepts admin/teacher roles.

## How to use
- Student: register, log in, open a published course, enrol, open lessons and mark lessons complete.
- Teacher: admin creates a teacher account; teacher logs in and uses Teacher Dashboard to create courses, lessons, add MCQ questions and publish content.
- Admin: log in with the manually seeded admin account; use Admin Dashboard to manage users and roles. Admin can also access teacher course management.

## Bilingual content
The site stores each user's preferred language (`en` or `hi`). This starter has bilingual-ready structure, but most interface copy is currently English. To complete Hindi localization, add translation dictionaries for every page and wrap visible strings in translation helpers. Course content can be authored in Hindi or English by teachers.

## Production deployment checklist — required before public launch
This is a functional starter, not a security-audited production service. Before launching publicly:
- Set HTTPS and secure cookie flags (`Secure`, `HttpOnly`, `SameSite=Lax`) in PHP/session configuration.
- Move database credentials to environment variables or a secret manager; use a least-privilege DB account.
- Set `BASE_URL` to the real deployment path and disable PHP error display in production.
- Add rate limiting / login throttling, email verification, password reset, email delivery and account recovery.
- Add upload handling through a dedicated secure storage service; do not allow arbitrary executable uploads.
- Validate and allowlist video/audio host URLs; consider embedding through trusted providers only.
- Add audit logs, moderation/reporting, backups, monitoring, privacy policy, terms, cookie notice and data deletion/export workflows.
- Add pagination and stronger admin audit controls for large deployments.
- Add automated tests, dependency/security scanning, penetration testing and accessibility review.
- Review local privacy, consumer and child-safety requirements before allowing minors to register.

## Current scope limitations
- No payment gateway (intentionally: all courses are free).
- No built-in live streaming, real-time chat, AI tutor, speech recognition or certificate issuance yet.
- Quiz answer validation currently runs in the browser for this starter; secure graded attempts should be implemented server-side before using scores for certificates or rankings.
- Teacher can manage courses they own; admins can manage users and access teacher tools.
- No media upload endpoint is included. Teachers can add trusted media URLs.

## V2 additions — Speaking, pronunciation and certificates
Import `database/v2_upgrade.sql` after the original schema when upgrading an existing installation.

### Speaking Tutor
- `speaking.php` uses browser Web Speech API recognition (`SpeechRecognition` / `webkitSpeechRecognition`) where supported.
- It shows the speech transcript, gives a simple transcript-overlap practice indicator and saves practice attempts to MySQL.
- Browser recognition support and quality vary by browser, operating system, locale and network. Some browsers send audio to their own speech service.
- This is a guided speaking practice feature, not a true generative AI tutor or validated phoneme-level pronunciation scoring. For a true AI tutor, connect a server-side AI provider with a private API key, explicit consent, audio/data retention controls and cost limits. Never expose provider API keys in JavaScript.

### Audio Pronunciation
- `pronunciation.php` uses browser `speechSynthesis` for built-in phrase playback and custom text.
- Voice availability varies by device. This is not a recorded native-speaker audio library.

### Certificates
- Students unlock `certificate.php?course_id=ID` after completing every published lesson in an enrolled course.
- A unique certificate code is stored in the `certificates` table and can be checked at `verify.php?code=...`.
- Use Print → Save as PDF to create a PDF copy. Certificates are platform completion records, not accredited qualifications.

### Bilingual interface
- Header language switch changes the preferred interface language to English or Hindi.
- Core V2 tutor and pronunciation screens include English/Hindi copy. Some older pages and teacher/admin authoring areas still contain English-only labels; complete localization requires translating every remaining string.
