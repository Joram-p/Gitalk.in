GITalk.in SEO STARTER PACKAGE

Files:
- index.html: SEO-ready homepage
- travel-accessories.html: example SEO article/affiliate guide
- style.css: responsive styling
- robots.txt: crawler rules + sitemap location
- sitemap.xml: URLs to submit in Google Search Console
- 404.html: custom not-found page

UPLOAD:
Upload these files to the root/public folder of your GitHub Pages website.

IMPORTANT:
1. Keep HTTPS enabled for https://gitalk.in/
2. After deployment, check:
   https://gitalk.in/
   https://gitalk.in/robots.txt
   https://gitalk.in/sitemap.xml
3. Add https://gitalk.in/ to Google Search Console and verify ownership.
4. Submit https://gitalk.in/sitemap.xml
5. Replace the example content/products with your own original, useful content.
6. Before publishing affiliate links, add the required affiliate disclosures and follow the affiliate program's current terms.
7. If your real site has more pages, add every canonical/indexable page to sitemap.xml.

This is a starter SEO package, not a guarantee of Google ranking.
