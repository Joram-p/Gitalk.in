GITALK.IN AFFILIATE AUTO-UPDATE SYSTEM

1. Upload this folder to your GitHub repository.
2. Put real product images inside assets/images/.
3. To change an affiliate link, edit ONLY:
   data/affiliate-links.js
4. The product's affiliateKey in data/products.js must match the key in affiliate-links.js.
5. To add a new product:
   - add its link in affiliate-links.js
   - add its product object in products.js
   - add its image in assets/images/

IMPORTANT:
This system centralizes links across your own site. It cannot automatically create or discover new Amazon affiliate links without an authorized Amazon/affiliate API or manual link source.
