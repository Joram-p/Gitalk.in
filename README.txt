GITALK.IN — JAPANESE-INSPIRED REDESIGN

Files:
- index.html: home page (keep this filename in the published root)
- style.css: responsive light Japanese-inspired theme
- script.js: mobile navigation and current year
- 404.html: custom not-found page
- privacy.html and contact.html: starter pages

PUBLISH TO GITHUB PAGES:
1. Download and unzip this package.
2. Open the GitHub repository: Joram-p/Gitalk.in
3. Upload the files into the repository root (not inside an extra nested folder).
4. Make sure the home page is named exactly index.html (lowercase).
5. Commit the changes to the branch selected in Settings > Pages (commonly main / root).
6. Open Settings > Pages and confirm the published URL shown there.
7. Wait for deployment to finish, then refresh the published URL. If the domain still shows 404, check the custom-domain/DNS settings and the exact Pages URL.

IMPORTANT:
- This is a static front-end redesign; it does not include a database, login, email verification, AI video generation backend, or monetization integration.
- The home page links to sections on the home page. The tool cards are design placeholders until real tools/pages are connected.
- Update the contact email and privacy policy to match your actual setup before launch.
- Google Fonts are optional; the page uses fallback system fonts if they are unavailable.
