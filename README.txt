# Gitalk.in — Professional Theme

A responsive, modern landing page redesign for Gitalk.in.

## Files
- `index.html` — homepage
- `style.css` — responsive styling and theme
- `script.js` — mobile navigation and current year

## Publish on GitHub Pages
1. Download and extract the ZIP.
2. Open your GitHub repository in a browser.
3. Back up your existing `index.html`, `style.css`, and `script.js` first.
4. Upload the three files from this folder to the repository root, replacing the matching files.
5. Commit the changes to the branch used by GitHub Pages (often `main`).
6. Wait for the Pages deployment to finish, then refresh Gitalk.in.

This is a front-end theme only. Login, user profiles, posts, comments, and community membership need a backend such as Supabase and are not activated by this visual template.
