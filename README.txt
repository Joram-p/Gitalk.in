GITALK SOCIAL - READY FILES

Files:
1. index.html
2. script.js
3. firebase-storage-rules.txt
4. firestore-rules.txt

SETUP:
- Upload index.html and script.js to your GitHub Pages repository.
- Firebase Authentication: enable Email/Password.
- Firebase Firestore: create the database.
- Firebase Storage: enable Storage.
- Paste firebase-storage-rules.txt into Storage > Rules and Publish.
- Paste firestore-rules.txt into Firestore Database > Rules and Publish.

The app supports:
- Email signup/login
- Text posts
- Photo upload up to 10 MB
- Video upload up to 50 MB
- Firebase Storage media upload
- Firestore feed
- Likes
- Comments
- Share
- Mobile responsive layout
