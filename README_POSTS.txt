GITALK.IN EASY POST SYSTEM

Files:
- index.html = main website
- posts.js = latest posts data

To add a new post:
1. Open posts.js.
2. Copy an existing { ... } post object.
3. Paste it before the closing ];
4. Change title, category, description, date, author, icon, tags and link.
5. Save posts.js and upload/replace only posts.js on GitHub.
