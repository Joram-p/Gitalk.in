GITALK.IN ENGLISH ACADEMY
=========================
यह GitHub Pages compatible static website है।

FEATURES
- Hindi to English course: 12 structured modules
- Daily spoken English practice + browser speech playback
- Microphone recording practice (browser permission required)
- 1,200 question practice bank with explanations
- 20 / 50 / 100 question mock tests
- Online English dictionary search (dictionaryapi.dev; internet required)
- Progress saved in the visitor's browser localStorage
- Mobile responsive layout

GITHUB PAGES पर लगाने के चरण:
1. ZIP extract करें।
2. GitHub repository https://github.com/Joram-p/Gitalk.in खोलें।
3. Add file > Upload files चुनें।
4. इस ZIP के अंदर की index.html और README_HINDI.txt को repository के root में upload करें।
5. Commit changes करें।
6. Settings > Pages में Deploy from branch, main, /(root) चुनें (यदि पहले से enabled है तो बदलने की जरूरत नहीं)।
7. कुछ मिनट बाद https://gitalk.in खोलकर Ctrl+F5 / browser refresh करें।

महत्वपूर्ण:
- यह frontend learning website है। इसमें अभी user accounts, cloud sync, teacher dashboard, certificate verification या payment system नहीं जुड़े हैं।
- Mock test question bank में 1,200 generated practice entries हैं, जो कुछ core grammar/vocabulary templates को repeat करके बनती हैं; इसे editorially reviewed 1,200 unique questions न समझें। आगे विस्तृत unique question bank जोड़ी जा सकती है।
- Online dictionary के लिए dictionaryapi.dev public API का उपयोग होता है। यह मुख्यतः English definitions/pronunciation देता है, हर शब्द का Hindi translation guaranteed नहीं है।
